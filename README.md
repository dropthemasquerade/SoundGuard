# SoundGuard

Cyberpunk-style local sound recognition and persistent alarm for iPhone.

**HEAR · ALERT · PROTECT**

Open `SoundGuard.xcodeproj` in Xcode 15.2+, select a development team, and run on a real iPhone. The microphone, alarm audio, and haptics need a device; the simulator can compile and run unit tests.

App icon is generated from `appIcon.png`.

Architecture, permissions, background limits, and the test plan: [Docs/ARCHITECTURE.md](Docs/ARCHITECTURE.md).
